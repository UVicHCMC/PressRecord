# Workflow for XML Records

This document is for RAs who are completing XML records for gameplay videos in the Press Record collection. 

1. Before you get started, open the schema so you can search the metadata elements and their controlled vocabularies while you're completing XML records: https://github.com/UVicHCMC/PressRecord/blob/dev/sch/gameplayMetadataSchema22Sept26V1.md (Markdown file) or https://github.com/UVicHCMC/PressRecord/blob/dev/sch/gameplayMetadataSchema22Sept26V1.pdf (PDF file).
2. Select an XML file from https://github.com/UVicHCMC/PressRecord/tree/dev/xml/data/01pass. You will conduct a "second pass" on this file.
3. Move that XML file to https://github.com/UVicHCMC/PressRecord/tree/dev/xml/data/02pass.
4. Find the corresponding gameplay file at the URL I provide. It will have the same filename as the XML file, except it'll be a video file (MP4). 
5. Watch the gameplay video several times. Use your computer or a pen/pencil and paper to take notes. 
6. Complete your second pass on the XML file, adding and correcting metadata where necessary. As you do, record pertinent notes in "3J. Platform Edition Note," "4K. Gameplay File Note," "5H. Gameplay Settings Note," "6FF. Gameplay Footage Note," and "7C. Gameplay Instruction Note." Your notes in these five elements should describe aspects of the gameplay video that are not adequately addressed by other metadata elements in the schema. Write them with search in mind.
7. Save the completed XML record on your local drive. Don't change the filename.
8. Upload/push the XML file to https://github.com/UVicHCMC/PressRecord/tree/dev/xml/data/02pass.
9. Optional: add any corrections to or suggestions for the schema to https://github.com/UVicHCMC/PressRecord/blob/dev/schemaRevisions.md. Save and upload/push the changes. 
10. Update the project journal at https://github.com/UVicHCMC/PressRecord/blob/dev/journal.md. Use your initials if you'd rather not use your name. Save and upload/push the changes.
